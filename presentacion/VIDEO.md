# Preparación del vídeo

Este documento centraliza la preparación del vídeo explicativo y la demostración de **Memory Quest: Señal estelar**.

## Requisitos de entrega

- La explicación debe realizarla la alumna.
- La grabación debe incluir obligatoriamente la captura de pantalla.
- Mostrar el rostro mediante una cámara es opcional.
- El vídeo debe estar disponible mediante un enlace accesible para la evaluación.
- La URL definitiva deberá añadirse al README y al formulario de entrega.

## Materiales previstos

- Slides definitivas.
- Capturas de pantalla finales.
- Diagrama de arquitectura exportado.
- Imagen de portada.
- Guion del vídeo.
- Aplicación desplegada y preparada para la demostración.
- Enlace de acceso al vídeo final de YouTube.

## Estructura inicial

1. Presentación breve del proyecto.
2. Problema educativo y propuesta.
3. Recorrido por las slides principales.
4. Demostración de una partida.
5. Arquitectura y uso de inteligencia artificial.
6. Calidad, seguridad y despliegue.
7. Resultado, aprendizajes y posibles ampliaciones.
8. Cierre con los enlaces del proyecto.

## Demostración prevista

- Mostrar la pantalla inicial y comenzar una nueva partida.
- Enseñar una pareja correcta y una selección incorrecta.
- Explicar la energía, el cronómetro y la barra de reparación.
- Mostrar una transición entre capítulos.
- Comprobar que el progreso puede recuperarse desde el navegador.
- Mostrar brevemente el desenlace o una partida ya preparada para evitar alargar la grabación.

## Pendiente

- Cerrar los textos de las slides.
- Preparar el guion completo con tiempos y acciones en pantalla.
- Seleccionar la herramienta de grabación.
- Realizar una grabación de prueba.
- Grabar y revisar la versión final.
- Publicar el vídeo y comprobar el enlace en una ventana privada.

No se almacenarán claves, credenciales reales ni grabaciones con información privada en el repositorio.
