# Arquitectura

Documento reservado para describir la arquitectura cuando se seleccione el stack.

Como mínimo deberá documentar:

- Diagrama de contexto.
- Componentes del frontend.
- Motor y estado del juego.
- Necesidad o ausencia de backend y contratos de API.
- Modelo de datos.
- Biblioteca de contenidos e imágenes.
- Persistencia local mediante `localStorage`.
- Estrategia de pruebas.
- Despliegue y observabilidad.

## Principio inicial

El MVP no dependerá de servicios externos de IA. Las reglas, el contenido educativo y la narrativa estarán definidos localmente, y el progreso se conservará en el navegador sin cuentas ni base de datos.
