# Requisitos de entrega del TFM

Resumen operativo basado en las [especificaciones oficiales de entrega](ESPECIFICACIONES-OFICIALES-ENTREGA-TFM.pdf), cuya copia se conserva en este mismo repositorio para centralizar la documentación del TFM.

## Repositorio

- Repositorio público en GitHub como opción preferente.
- Código fuente completo.
- Documentación incluida en el repositorio.
- Si el repositorio fuese privado, deberá justificarse y concederse acceso al evaluador indicado por la organización.

## README final

El README deberá incluir:

- Descripción general.
- Stack tecnológico.
- Instalación y ejecución.
- Estructura del proyecto.
- Funcionalidades principales.
- URL del proyecto desplegado.
- URL de las slides.
- URL del vídeo.
- Usuario y contraseña de prueba si existe login.

## Despliegue

- Publicación del proyecto funcionando siempre que sea posible.
- URL accesible incluida en la documentación y en el formulario.

## Presentación

- Slides con una explicación del proyecto.
- Enlace público o documento incluido en el repositorio.

## Vídeo

- Explicación realizada por la alumna.
- Captura de pantalla obligatoria durante la explicación.
- Mostrar el rostro es opcional.
- URL pública añadida al README y al formulario.

## Datos solicitados en el formulario

- Nombre completo.
- Correo utilizado en la inscripción.
- URL del repositorio.
- URL del despliegue, si existe.
- URL de las slides.
- URL del vídeo.
- Credenciales de prueba, si existe login.
