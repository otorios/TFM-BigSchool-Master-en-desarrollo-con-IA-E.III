# Material para la demostración

Esta carpeta contendrá recursos relacionados con la presentación y el vídeo que deban conservarse en el repositorio.

Elementos previstos:

- Capturas de pantalla finales.
- Diagrama de arquitectura exportado.
- Imagen de portada.
- Guion del vídeo.
- Enlace de acceso al vídeo final de YouTube.

No se almacenarán claves, credenciales reales ni grabaciones con información privada.
